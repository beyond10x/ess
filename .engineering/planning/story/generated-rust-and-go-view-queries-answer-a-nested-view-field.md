## Need

A served view with a nested view field (`story:a-view-field-nests-source-fields-under-a-struct-member`)
must be answered by the generated Rust and Go view queries, or refused by them by name. A view
field with `expr:` is kept an obligation named by its expression
(`website/docs/guides/specify/values-and-views.md`, after the operator table). A nested mapping of
plain source fields needs no evaluator: each member is a copy of one stored field.

## Acceptance

- `ess generate synthesize --target rust` and `--target go` on the reproduction model (served by a
  `reached_by: network` component) generate code that compiles, and whose `FileDetail` route answers
  `{"content": …, "metadata": {"id": …, "name": …}}` for a stored file. The generated served-HTTP
  test reads it back.
- A member whose source is `{expr: …}` keeps the view an obligation named by that expression, as a
  top-level `expr:` field does today. A member whose source is `{related: …}` is answered as a
  top-level navigated field is.
- Entity Runtime lowers no view (`docs/design/view-paging.md`, "Projections"), so it needs nothing.
- A model without a nested view field keeps its generated bytes.

## Fit review

1. **Need.** A generated server answers the nested row, or refuses it by name. Requester's syntax
   (theirs): "projected as the nested object in the generated schema and OpenAPI".
2. **Class.** Gap, following the parent story.
3. **Already expressible?** No (parent story).
4. **Fit.** Every target handles a construct or refuses it by name
   (`.agents/skills/assessing-external-requests/SKILL.md`, question 4). Plain copies are answered,
   and computed members follow the existing `expr:` obligation.
5. **Second adopter.** The address read of the parent story, served by a generated Go service.
6. **Cost.** Generated code changes only for models that declare the form.
7. **Alternatives.** (a) Keep every nested view field an obligation: honest, but needless for plain
   copies. (b) Answer copies and navigations, keep expressions an obligation: chosen.

## Decisions

accept, redesigned, as the parent story.
