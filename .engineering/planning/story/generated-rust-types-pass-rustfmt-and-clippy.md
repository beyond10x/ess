## Need

Reported by spindle wave 12 against ess 0.88.0. The Rust types that `ess generate types --target
rust` writes do not pass `rustfmt --check`, and fail `clippy -D warnings` with `derivable_impls`: a
hand-written `impl Default` that `#[derive(Default)]` with `#[default]` would express. Example:
spindle `crates/spindle-observe-api/types.rs:13`. An adopter that runs fmt and clippy over its
tree must exempt the generated file or patch it.

## Acceptance

- For every repository model the generator test suite already covers, the generated Rust types
  pass `rustfmt --check` and `clippy -D warnings`. That includes a model with an enum that has a
  default.
- The generated bytes change only in formatting and in the derived default. The byte-pin tables
  are re-pinned in the same change and name this story.

## Scope

- inferred: `crates/generate/ess-gen/src/` (the Rust types target), the types generation tests.
