## Need

`story:a-view-read-checks-every-rows-shape` puts the view's declared shape on `expect_view` and
`eventually_view` steps under `ess-conformance/64` and `/65` and checks it in the Rust runner. The
Go runtime that `ess verify conform synthesize --target go` writes must admit those majors and
apply the same check, or a Go implementation is held to less than a Rust one for the same suite.
Today it admits up to 63 (`go/runtime.go:104`, `go/mod.rs:430`) and compares only the named row
fields (`go/runtime.go:3811` `rowMatches`), while it already checks an event payload against its
shape (`go/runtime.go:4145` `holds`).

## Acceptance

- The generated Go runtime admits `ess-conformance/64` and `/65`, and admits `shape` on
  `expect_view` and `eventually_view` only from /64 (a /63 suite carrying it is refused before any
  target effect).
- Run on the suite/64 fixture of `story:a-view-read-checks-every-rows-shape`, the Go runtime fails
  the view step for a row missing `placed_at` and for `placed_at: 7`, and passes a conforming row,
  with the same verdicts as the Rust runner (a parity test under
  `crates/verify/ess-conformance/tests/`).

## Fit review

1. **Need.** Same as `story:a-view-read-checks-every-rows-shape`: a view row's declared fields are
   not checked; here, by the Go runtime. Requester's proposal (theirs): "the Go and TypeScript
   runtimes do the same" (they compare only named fields), fix in all.
2. **Class.** Gap, as in the parent story; a runtime that ignored the shape would be a target that
   "silently ignores the new construct" (`.agents/skills/assessing-external-requests/SKILL.md`,
   red flags).
3. **Already expressible?** No; see the parent story and `run.txt` § 2.
4. **Fit.** Reuses the Go runtime's own event shape check `holds` (`go/runtime.go:4145`) and its
   admission table (`go/runtime.go:946`); no new vocabulary.
5. **Second adopter.** Any Go service generated against a model with a view, for example
   `example.catalog.Products` with `price: Decimal`.
6. **Cost.** No format of its own: it admits the pair the parent opens. A Go package generated by
   an older `ess` refuses a /64 suite by major, as for every earlier pair.
7. **Alternatives.** Leave Go at /63 and have synthesis keep Go suites below /64: two suites per
   model, refused. Chosen: parity with Rust.

## Decisions

Accept, redesigned (the design is the parent story's; this is its Go target).
