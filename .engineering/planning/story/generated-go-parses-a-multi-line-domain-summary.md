## Need

Generated Go does not parse when a domain's `summary:` spans several lines: the summary is written
into a Go comment line by line without a comment marker on each further line
(`crates/generate/ess-synth/src/go/mod.rs`, ~984). Found by adversary pass 1 of
story:generated-rust-and-go-decoders-check-a-structs-distinct-invariant (pre-existing).

## Acceptance

1. A domain whose `summary:` holds several lines generates Go that `go build` and `go vet` accept;
   a test in `crates/generate/ess-synth/tests` pins it.
2. A one-line summary keeps its generated bytes.
