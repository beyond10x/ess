## Outcome

A column's or a record field's value can be the link to a page of the same document: a build's
digest opens the build page, with no separate row action and no host slot. Both renderers draw the
value as that link with its params read from the row, and an `ess-ui-test/1` test acts on the cell
in both renderers and then expects the page.

## Context

A downstream page generator needs a table in which the value itself opens the detail page, and no
`Open` button in the row.

What ESS does today:

- A column or record field is a `Field` (`crates/ui/ess-ui/src/model.rs:2502-2546`,
  `deny_unknown_fields`). It has no key that names a page.
- `as: link` draws the value as an external address in React: `safeUrl(value)` in an `<a href>`
  (`crates/ui/ess-ui-react/templates/runtime/fields.tsx.tmpl:172-182`). It cannot name a page of
  the document.
- The `link` primitive has `to` (a `Navigate`: a page and params) and `href`
  (`model.rs:2443-2451`, `:3086-3093`), but a column is a field, not a primitive. A collection's
  `item` composite may hold a link primitive, for cards, list and tree collections only; a table has
  columns.
- A row action may `navigate` to a page (`model.rs:3027`), which draws a separate button.
- A field host slot draws anything, but a test cannot act inside a host slot: any step but `expect`
  at one is refused (`website/docs/reference/ess-ui-test.md:412-446`, last row of the table), and the
  terminal draws only its label.
- `act` at a cell is refused: an `act` target must name an action (`crates/ui/ess-ui-test/src/runner.rs:1268-1275`,
  "is not an action"); at a column header it sorts (`ess-ui-test.md:148-170`).
- `ess ui check` resolves a page name under `page_refs` (`crates/ui/ess-ui-check/src/rules.rs:596`).

The requester's proposal, restated and labelled as theirs: a column or record field declares a
page to open in the shape `link.to` has, `{to: <page>, params: {<name>: <expression over row>}}`;
both renderers draw the link; `act` at the cell opens the page.

## Acceptance

1. Red first: `ess ui load` accepts a column `{field: digest, navigate: {to: builds.detail, params:
   {id: row.id}}}` (the spelling of decision CL-D1 A). Today it is refused as an unknown key of
   `Field`. The case goes in `crates/ui/ess-ui/tests/`.
2. `ess ui check` resolves the page under `page_refs` and each param expression against the row,
   and reports a name that is no page at the field's path. With `--model`, a param that reads a
   field the view lacks is `row_fields`.
3. The terminal and the React runtime draw that value as a link to the page with the params
   evaluated on the row. A row whose param is absent draws the value as plain text (CL-D2).
4. `act` at the cell (`…/rows/<key>/columns/<name>`, or the record field's path) opens the page in
   the terminal and in the Playwright spec, and an `expect` after it sees the page.
5. The step stays refused where the parity rules already refuse it (a column cell of a cards, list
   or tree collection with an `item`), with the same reason in both renderers. A `select` of the row
   keeps moving the cursor and does not follow the link.
6. The `ess-ui/1` reference, generated by `ess ui docs`, lists the key, and `CHANGELOG.md` names it
   under `### Added`.

## Fit review

Tree `2e055bcd0c` (branch `plan/gap-reports-2026-11-24`), read-only. This story covers requirement 3
of a downstream page generator's report of 2026-11-25.

1. **Need.** A value that is the link to the page about it, testable. Minimal reproduction (fresh,
   not run here): a table over a view `builds.List` with columns `id` and `digest`; no document
   makes the digest open `builds.detail` except a row action beside it or a host slot.
2. **Class.** *Gap*, not a convenience: the idioms move the checked figure. A row action draws a
   button, not the value as the link. A host slot draws the link where no test can act (parity
   table, last row). A `link` primitive in an `item` does not exist for a table's columns.
3. **Already expressible?** No (Context above). Skill question 3's condition is not met by the host
   slot: the figure leaves the specification and the suite.
4. **Fit.** No grid applies (`docs/design/language-grids.md:15`). It reuses `Navigate` and the
   `page_refs` and `row_fields` checks. The concept "go to a page with params" is spelled
   `navigate` on an action and `to` on a `link` primitive, so the key's spelling is a decision
   (CL-D1), not the requester's. It is general across siblings: a column and a record field are one
   `Field`, and a field of a form is not a display, so it refuses the key as it refuses `tone`
   (`model.rs:2531-2536`, "only a column or record field is toned"). Every target is named: the
   terminal, the React runtime, the test runner, the checker and generated docs.
5. **Second adopter.** A ticket table whose requester name opens the requester's page; an orders
   list whose customer id opens the customer page.
6. **Cost.** One optional key on `Field` in `ess-ui/1`: a document without it keeps its meaning, so
   no new version. A new case of `act` at a cell, a reference line, a checker rule.
7. **Considered.** (a) Change nothing: a row action or a host slot. (b) `navigate` on a field, the
   action's spelling (chosen). (c) `to` on a field, the link primitive's spelling. (d) A second
   `as` value for a link to a page. The request's shape (`link.to`) is taken for what it holds
   (`{to, params}`) and not for the key name.

**Accept, redesigned.** The need is adopted; the key is spelled as an action spells it, and the key
is not accepted before the owner's read.

## Decisions

Would add to `ess-ui/1`: `navigate` on a column or record `Field`, the shape of an action's
`navigate` (waits for the owner's read before a release). Would add to `ess-ui-test/1`: nothing
(an existing `act` reaches a new node).

- **CL-D1. How is a field's page spelled?** (A) `navigate: {to, params}`, as an action spells it.
  (B) `to: {to, params}`, as the `link` primitive spells it. (C) A second `as` value that carries
  the page. (D) Change nothing: the row action and the host slot stay. **Recommended: A.** Open,
  the coordinator's.
- **CL-D2. What does a cell draw when a param of the link is absent for its row?** (A) The value
  as plain text, with no link. (B) An empty cell. (C) Refuse the run. **Recommended: A.** Open, the
  coordinator's.
