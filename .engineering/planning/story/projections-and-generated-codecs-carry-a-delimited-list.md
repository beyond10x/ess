## Need

A list newtype with `encoding: {delimited: […]}`
(`story:a-list-newtype-declares-a-delimited-wire-encoding`) must be published and read as one
delimited value. Today OpenAPI publishes a list view parameter as a repeated key (`style: form`,
`explode: true`, `crates/generate/ess-gen/src/openapi.rs` `view_parameters`). A generated client
would send `q=a&q=b`, and a generated server would refuse or misread `q=a,b c`.

## Acceptance

- `ess generate --kind openapi` writes such a parameter as `{"type": "string"}` with
  `x-ess-delimited: [",", " "]` and a description naming the separators. Where the only separator
  is `,` it writes `{"type": "array", "items": …, "style": "form", "explode": false}` instead. A
  body member of the type is a string with the same marker.
- Generated Rust and Go servers read `q=a,b c` for the reproduction view as `["a", "b", "c"]`
  (`q=a,,b` as `["a", "b"]`) and write the value joined by the first separator. Their encoders refuse
  an element that is empty or holds a separator, with a named error.
- The TypeScript types target writes the type as `string`, documented as delimited. Targets that
  cannot carry it (Web, Clap) refuse it by name at generation.
- A model with no delimited list keeps its projection and generated bytes.

## Fit review

1. **Need.** The published contract and the generated code carry the declared delimited form.
   Requester's syntax (theirs): "A declared tokenizing wire form", which a projection must publish.
2. **Class.** Gap, following the parent story.
3. **Already expressible?** No (parent story).
4. **Fit.** The OpenAPI form for comma-only (`explode: false`) is the standard spelling. Any other
   separator set has no standard form, so it gets an `x-ess-` marker, as other declared constraints
   do. Every target handles it or refuses it by name.
5. **Second adopter.** The `ids=1,2,3` read of the parent story, which a generated client must send
   in that form.
6. **Cost.** Projection and generated bytes change only for models that declare the key.
7. **Alternatives.** (a) Always a string with a marker: refused for comma-only, where OpenAPI has a
   standard form. (b) Standard form where one exists, marker otherwise: chosen.

## Decisions

accept, redesigned, as the parent story.
