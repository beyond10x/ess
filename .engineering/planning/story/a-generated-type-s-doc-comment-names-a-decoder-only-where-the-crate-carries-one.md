## Need

The generated Rust and Go types say, on every type with an invariant, alphabet or prefix, that "the generated decoder refuses a value
that breaks" it. A crate generated for a specification with no served component carries no decoder, so the sentence names code that
is not there.

Where the sentence is written:

- `crates/generate/ess-synth/src/rust/items.rs:69` (newtype) and `:107` (struct);
- `crates/generate/ess-synth/src/go/items.rs:202` (newtype) and `:244` (struct).

Where the decoders are emitted: the Rust wire module only from `rust/http.rs:175-181` (`server_crate`, which returns nothing when no
component is `reached_by: network`, `http.rs:122-130`) and from the web bridge (`web/mod.rs:321`); the Go decoders only with a server.
`ess generate synthesize --layout crate`, the workspace layout and the Go target on a model of types and entities only were run on
installed 0.98.0 (brand-free, a struct `demo.run.Tally` with `invariants: [passed <= executed]`): none of the three outputs holds a
function that takes a `json::Value` outside `json.rs` or a `decode` function in Go, and each still carries the sentence
(`out-crate/src/run.rs:21`, `out-ws/crates/demo-types/src/run.rs:21`, `out-go/types/run/run.go:35`).

## Findings covered

- Gap 9 of the thirteenth report, the doc comment (the request for a wire module without a transport is a decision, FM-D9).

## Fit review

1. Need: a doc comment that states what the crate holds. Documentation of generated code is part of its contract: a reader trusts it.
2. Class: defect, a documented behaviour the generated crate does not have.
3. Expressible today: not applicable.
4. Fit: the rest of the sentence is true everywhere: `broken_constraint` exists on the type whether or not a decoder calls it. The
   unconditional wording "which a decoder calls to refuse a value that breaks one" names what the method is for and claims no emitted
   decoder, so no per-layout branch and no decision is needed.
5. Second adopter: any specification generated as a library.
6. Cost: four string literals; the generated bytes of every model with a constrained type change, so committed generated trees that
   carry the sentence regenerate: `generated/rust/billing/crates/billing-types/src/invoice.rs`, `generated/rust/gatepass/crates/gatepass-types/src/visit.rs`,
   `generated/go/billing/types/invoice/invoice.go`, `generated/go/gatepass/types/visit/visit.go`, and any byte pin that holds them
   (the gate's `projection-check`; `ess-synth` `feasibility`, `adv319`, `http_binding_rust` compare example trees byte for byte).
   No format, no IR, no diagnostic.
7. Alternatives: emit the decoder so the sentence is true (FM-D9 B, a larger change, kept as its own decision); keep the sentence.

8. Not built, decided 2026-11-24 16:36 CET (the coordinator, under the owner's delegation): FM-D9 B, a switch by which `--layout crate` emits the wire module for every type when asked, so a library crate decodes without a server. It is recorded as a draft only and has no story; this story makes the comment true without it.

## Decisions

Accept as proposed. No decision is open for this story. FM-D9, a wire module in the crate layout without a transport, is the other half of the gap: decided on 2026-11-24 16:36 CET (the coordinator, under the owner's delegation) as B, recorded as a draft only and not built (see the Fit review).

## Acceptance

- doc_comment_claims_no_missing_decoder: the types of a synthesized Rust crate (both layouts) and Go module for a model with no served
  component carry no sentence naming "the generated decoder", and the sentence that remains reads "Checked by `<Type>::broken_constraint`,
  which a decoder calls to refuse a value that breaks one" (Go: `BrokenConstraint`).
- served_models_keep_a_true_sentence: the same model with a component `reached_by: network` generates the same sentence, and its
  decoder calls `broken_constraint` (the existing decoder test holds this).
- committed_trees_are_regenerated: the four generated example files above are regenerated in the same change, and `task projection-check`
  passes.
