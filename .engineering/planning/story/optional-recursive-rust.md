## Acceptance

A compiler-admitted struct with an optional self-reference synthesizes into fresh Rust code that compiles and round-trips its declared JSON without changing already successful acyclic generation; unsupported recursion still receives a source-addressed target refusal.

## Context

Adopter issue https://github.com/beyond10x/ess/issues/400 records complete EKR failures on two released tools. The operator's execution plan explicitly requires resolving generation before generating new runtime contracts. Existing refusal is correct; this work extends target coverage.

## Fit review

1. Need: a type descriptor has an optional child descriptor. Minimal reproduction is a brand-free demo.core.Link with next: Optional<demo.core.Link>. Validation succeeds; synthesis returns recursive-layout. See rust/feasibility.rs size_reference/size_cycles.
2. Class: target coverage gap, not invalid source or broken validation. docs/design/review-rust-target-feasibility.md intentionally refused these cycles.
3. Existing idiom: enum labels already support separate name/wire via ess-domain/src/types.rs EnumVariant and rust/wire.rs. A minimal DocumentV1 with wire demo.document/1 validates and synthesizes on the installed release. Decline a new naming feature with this idiom. Optional currently renders Option<T>; changing to List changes meaning.
4. Fit: no authored Box keyword or IR change. Choose deterministic Rust indirection for optional self-recursive structs, shared by types, codecs, accessors and feasibility. Rust/Web share wire generation. Either support each reached composition or explicitly refuse before emitting broken code. Keep unsupported cycles refused.
5. Second adopter: nested configuration type descriptors and document-editor parent descriptors independently require optional recursive nodes. This follows the already admitted Optional<NamedType> model.
6. Cost: a separately accepted representation design, since the previous feasibility design reserved boxing; no source/wire format migration. Previously successful generated bytes stay unchanged. Explicit downstream enum name/wire adoption changes specification identity/digests despite preserving serialized values.
7. Alternatives: unchanged refusal does not meet generation need; replacing Optional by List changes cardinality; boxing every Optional breaks existing APIs; general arbitrary-cycle boxing is deferred. Prefer bounded self-recursive struct support with fresh compilation evidence.

## Decisions

Accept, redesigned: use the existing enum wire idiom downstream; implement optional self-struct indirection as a Rust target representation decision. The operator's implementation request authorizes the prerequisite fix. Do not change domain semantics, bypass feasibility, or hand-transcribe downstream models. Unsupported mandatory and mutual/newtype/union cycles retain diagnostics. If context-free boxing of references to newly admitted recursive types is needed to compose with accessors, document that representation and prove all affected constructors/codecs agree before accepting it.

## Scope

Cited: crates/generate/ess-synth/src/rust/layout.rs, items.rs, feasibility.rs and wire.rs hold representation, emission and cycle refusal. Cited: rust/accessor.rs traverses fields using semantic types and must remain compilable. Inferred: behavior/invariant/selection construction seams need review. New focused tests and docs/design/optional-recursive-rust.md; CLI tests only if CLI behavior needs new coverage. No other product feature or naming allocator rewrite.
