## Need

A generated server and client must decode and encode an encoded `Timestamp` newtype
(`story:a-timestamp-newtype-declares-its-wire-encoding`) as the integer the wire carries, wherever
the type appears: a JSON body member, an event payload, a view row and a query parameter. Without
it a generated route would refuse `filters.created.from=1730851200` as a malformed instant, or
silently answer RFC 3339 text.

## Acceptance

- `ess generate synthesize --target rust` and `--target go` on the reproduction model (a served
  view whose parameters are `example.calls.EpochInstant`, `encoding: unix_seconds`) generate code
  that compiles; its view route decodes `filters.created.from=1730851200` as the instant
  2024-11-06T00:00:00Z and applies the filter, and refuses `1730851200.5` and `abc` with the
  binding's `malformed` status, naming the parameter.
- An encoded field in a command body, an event payload and a view row is written as the integer and
  read back to the same instant; an instant that is not a whole second (`unix_seconds`) or a whole
  millisecond (`unix_millis`) is refused at encoding with a named error, never truncated.
- The TypeScript types target writes the type as `number`, documented as seconds (or milliseconds)
  since the Unix epoch.
- A target that cannot encode the type (Web, Clap, Entity Runtime lowering) refuses it by name at
  generation, at the type's declaration.
- A model with no encoded `Timestamp` keeps its generated bytes.

## Fit review

1. **Need.** Generated code reads and writes the declared wire form. Requester's syntax (theirs):
   "carried into ... every projection that writes or parses the parameter".
2. **Class.** Gap, following the parent story.
3. **Already expressible?** No (parent story).
4. **Fit.** Every target handles the construct or refuses it by name
   (`.agents/skills/assessing-external-requests/SKILL.md`, question 4). A value that cannot be
   written exactly is refused, never rounded, matching the exact-number rule
   (`docs/design/generic-language-features.md`, "Exact numbers").
5. **Second adopter.** The webhook event of the parent story, published by a generated Go service.
6. **Cost.** Generated code changes only for models declaring the key. The query decoder change is
   breaking only for such models.
7. **Alternatives.** (a) Refuse every encoded `Timestamp` in generated code by name: honest, but it
   leaves the adopter's served read hand-written. (b) Rust and Go codecs, TypeScript types, named
   refusals elsewhere: chosen.
