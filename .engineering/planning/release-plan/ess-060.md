## Intent

Release ESS 0.60.0 as one pass over every open GitHub issue of 2026-10-13 that this repository's own work closes: the wave 2026-10-11j content (https://github.com/beyond10x/ess/issues/515, `ess-http/1` stage 1, Go import cycles), `ess-http/1` stage 2 (https://github.com/beyond10x/ess/issues/493), contract roles (https://github.com/beyond10x/ess/issues/525), the explorer and mutation issues (https://github.com/beyond10x/ess/issues/535 to https://github.com/beyond10x/ess/issues/539), the specification language issues (https://github.com/beyond10x/ess/issues/530 to https://github.com/beyond10x/ess/issues/534), the YAML dependency (https://github.com/beyond10x/ess/issues/541), macOS provenance (https://github.com/beyond10x/ess/issues/548) and https://github.com/beyond10x/ess/issues/550.

0.60.0 was prepared and never tagged. The operator, 2026-10-13: every fix merges as a local commit into one integration branch, `integrate/ess-issues-20261013`; one full gate runs locally on its final head; then one push, one pull request with a `Fixes` line per issue, and one release. The release plans for 0.61.0 to 0.64.0 are folded into this one and archived.

The ESS-owned parser and emitter (that page's units n6 and n7) are `story:ess-yaml-owns-its-parser-and-emitter`, after this release.
