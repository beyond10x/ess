F1 (warning) `src/go/explore.go:1574` (and `:1561`, `src/ts/explore.ts:1244`, `:1259`): a null stored field makes a `when_subject` predicate Unknown, and `exploreMissing` reports the alphabetically first path (`input.*`), so both explorers exclude the whole command as "unknown over a generated input" instead of reporting undetermined and redrawing as the docs say. Red: `Use` excluded over one row's null `uses`.

F2 (note) `explore.go:1470`, `explore.ts:1163`: every stored-row branch is evaluated before choosing, so a later branch reading an unset field discards draws the interpreter answers with the first holding branch (`Annotate/spent` never reached).

F3 (warning) `explore.go:1498`: when a stored-row refusal and an accepting `when` both hold, the draw is redrawn instead of following precedence (held row before accepting, as the interpreter and the precedence doc order them), so a target checking the accepting guard first passes in both lanes. Red: `ambiguous ["exploredraw.keys.Use: exhausted, bulk"]`.

F4 (note) `exploreFieldPools`/`fieldPools`: the #223 decision says `example:` values also feed enum pools; only integer and string inputs are handled.

Attacked and not broken: non-ASCII cutting in both lanes; seed stability on an unaffected spec (byte-identical go-result.json, 32,362 bytes, against base); map iteration order; resize overflow; existence order; held state plus wrong_state; concurrent explorer.
