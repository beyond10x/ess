# Wave of 2026-11-22: twelve unit stories, one integration, one review

The operator's order, typed on 2026-11-22: "selecting the next ten stories then make sure the
description and the scope is absolute. Detailed and correct and fully clear what needs to be
done. […] all of that as one separate unit. Each story is implemented by a medium sonnet. Then
all is integrated and then all is reviewed as a whole once."

This page is the plan and the record of that wave. It stands beside
[zero-open-issues.md](zero-open-issues.md), whose plan is stopped; this wave is not a wave of
that plan. Skill: `aep:implementing`, wave mode, version 0.26.0, with the operator's variation:
no adversary pass per unit; one review of the integrated whole.

## What the wave serves

| goal | consumer gap or rule | units |
|---|---|---|

| a refusal that asks for a higher format names the file | a downstream specification's writer spent its budget on it | F1 to F3 |
| the organization rule "The local gate equals the forge" | a second full CI run on 2026-11-21 for a directory that exists only locally | L1 to L3 |
| the organization rule "Tests stay fast" | no test over 60 s is named today | T1 |

Order decided on 2026-11-21 (D1 = A): the path filter (pull request 807) and the 60 s report
first, then Binary64, then the paged view. The paged view is not in this wave: its design page
is not written.

## Dispatch

`subagent_type` `aep:implementor`, model Sonnet, effort medium, one agent per unit. Each
receives the common brief of the wave and its story. After the last unit is merged, one review
of the whole diff by `aep:adversary` and `aep:security-reviewer` on Opus, then the corrections,
then one pull request and one CI run.

## Pre-flight, 2026-11-22

- Free disk: 107 GB; builds queue below 50 GB. One tree that builds `ess-conformance` and
  `ess-cli` tests measured 26 GB on 2026-11-21; a tree that builds only `ess-xtask` 1.2 GB.

  once, and a finished unit's build directory is discarded before the next heavy one starts.
- Build pool: 14 builds running and 27 queued when the wave started; waits of 20 minutes were
  measured the evening before.
