# Legacy normalization templates

These five templates retain the exact emitted source bytes from ESS commit
`60ffcb2238ffef3a48d0db9555b6f2ca709ca2f7` for normalization formats 1–3.
Format 4 uses the live modules. Do not synchronize these snapshots with live
implementation changes: a legacy generation change needs an explicit migration.
The complete generated file maps are checked by `normalization_legacy_bytes.rs`.
