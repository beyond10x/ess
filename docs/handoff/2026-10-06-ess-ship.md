## CI facts learned today

- A push to a `queue/**` branch with an open PR runs CI twice (push and pull_request). GitHub
  requires every required check to pass in both suites: cancelling the duplicate push run left a
  cancelled `Gate` and macOS checks on `419da20dd` that blocked the merge, and GitHub answered 500 to
  every rerun or delete of that run. Do not cancel the duplicate; push a new head if it happens.
- Test shards ran out of runner disk (fixed: free runner disk, drop the workspace archive before
  the feature-off step); an archive download can hang for 43 minutes (fixed: 12-minute limit and one
  retry; on 2026-10-06 one shard still timed out both attempts and passed on a job rerun).
- `coverage_browser::a_start_past_the_deadline_is_a_fixture_environment_refusal_not_a_bidi_defect`
  failed once on CI and passed on rerun: the known browser-startup flake
  (`story:browser-fixture-startup-deadline`).
- `cargo xtask docs` refuses a release that is more than 3 minors ahead of the newest
  `website/blog` note; 0.55.0 added one.
