# UXF-005: graph nodes whose accessible name does not contain their visible label

axe `label-content-name-mismatch` (WCAG 2.5.3, serious): SVG groups of the domain graph
(`g[transform="translate(0,0)"]`, `g[transform="translate(360,0)"]` on the landing page) carry an
`aria-label` that does not contain the text they show. A speech-input user who says the visible
label does not reach the control.

2 pages, 4 configurations, 6 nodes: `/ess/` and `/ess/docs/visualise`, at both gating viewports.
Reported in the light theme only because the dark theme runs the colour rules alone
(`COLOUR_RULES` in `website/ux/core/contract.ts`).
