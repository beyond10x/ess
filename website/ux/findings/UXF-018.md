# UXF-018: table headers scroll away

The ess-31-release task ends on the `ess/31` row of `/ess/docs/reference/spec-versions` (the
shot). The row shows `ess/31`, `0.69.0` and a long description; the header row that says the
second column is "Introduced in" is about 19,000 px above, in a 19,705 px table (UXF-010). The
reader has to remember, or scroll back, what `0.69.0` means; the same page calls that column
"Released in" in its two other tables.

The same holds for every table taller than a screen: the CLI reference (the top half of the cli-middle moment of the
contact sheet shows rows whose header is off screen), diagnostics, and the 757 rows of
`/ess/docs/reference/ess-ui`.

Kept apart from UXF-010: shorter rows shorten the scroll, but a header that stays in view is a
separate change.
