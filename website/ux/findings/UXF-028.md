# UXF-028: the sidebar's bottom edge and the unnamed desktop-1440 page

R-04's sidebar rule (UXF-022) sets the docs sidebar's column to `max-height: 100vh` at 997 px and
wider. The sidebar starts below the navbar, so a long, expanded sidebar may be up to one navbar
height taller than the space left under it, and its last entries would sit below the viewport's
edge. Gate 2 checks that an element is in the viewport, not that its bottom edge is.

At the measured-only viewport desktop-1440 one page has an always-visible element out of view in a
gated state (R-03: 4). `round.json` counts it and names no page, so it cannot be told whether it is
the sidebar.

Affected: every doc page with an expanded sidebar at 1280 px and wider (unmeasured); 1 page at
desktop-1440. Cost S.

One line: name the page, then add a bottom-edge check to gate 2 and set the sidebar's
`max-height` to the space under the navbar if the check is red.
