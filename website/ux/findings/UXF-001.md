# UXF-001: the site has no search, on any page

Search is an always-visible element of the adapter (`website/ux/adapter.ts`, `alwaysVisible`) at
both gating viewports. No page of the built site renders a search control: 138 of the 139 pages,
548 of the 548 measured configurations (2 viewports x 2 themes); the 139th page,
`/ess/docs/reference/ess-ui`, was not measured (UXF-014).

Examples: `/ess/`, `/ess/docs`, `/ess/docs/start/install`.

A reader who knows a term (`ess/31`, a diagnostic code, a command) has to browse to it: see the
action counts of `ess-31-release` and `diagnostic-type-009` (UXF-010).

The regression asset is every L2 test; the one named fails on `search: missing` today.
