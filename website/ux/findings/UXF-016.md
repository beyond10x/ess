# UXF-016: the Status page's latest release is 46 releases old

The navbar's "Status" opens `/ess/docs/status/where-this-stands`. Its "Latest release" section
says "Latest published release observed on 1 October 2026: 0.51.0" and lists 0.47.0 to 0.51.0 as
"the last five releases"; its capability list is "statuses as of 2026-10-04" (the same
`website/data/status.json` feeds the landing page's figures).

Other pages of the same build say otherwise: the install page pins `version=0.97.1`, "What
changed" starts at "0.97.0 — 2026-11-21", and the release posts start at 0.97.

The page dates its claim, so the value has a source; but a reader who asks the Status page which
release is current, or what the last releases added, gets an answer seven weeks old.

One line: generate the "Latest release" section from the same source as the install page's pin.

## R-05: closed

The status page named 0.97.3, observed on 22 November 2026, while the install page installs
0.97.4, published on 2026-11-22 at 18:37 UTC with its four archives and `SHA256SUMS`. The status
page names 0.97.4 (observed 23 November 2026) and lists it first of the last five releases. The
L1 test above reads both built pages and failed before the change (`Expected: "0.97.4"`,
`Received: "0.97.3"`). It fails again when the install page moves to a newer release and the
status page does not.
