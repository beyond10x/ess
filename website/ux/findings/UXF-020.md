# UXF-020: the "next step" column out of view

The table of `/ess/docs/concepts/adoption-modes` has six columns. At desktop-1280 the shot shows
five ("MODE" to "WHAT IT DOES NOT") and a fade at the right edge of the content column; "next
step", the column that links each mode to the page to read next, is reachable only by scrolling
the table sideways. Gate 1 counts no spill, rightly: the table is its own scroll region.

Only this table is seen clipped in the round's shots. The docs hold 149 tables of five or more
columns (most in `/ess/docs/reference/ess-ui` and the CLI reference), so the probe should count
them rather than this page alone.
