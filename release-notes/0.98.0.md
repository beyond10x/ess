The Rust, Go and web targets carry a finite `Binary64`, and synthesis writes more scenarios for creating branches and row-set refusals.

**Breaking**

- Validation refuses an `exists: false` branch declared below a refusal it answers first; declare it before
- Validation refuses an ordering comparison over an enum; list the admitted variants with `in: [...]`

**Changed**

- `ess generate synthesize` carries a finite `Binary64` through the Rust, Go and web targets
- Synthesis writes more scenarios for creating branches that read or create related rows
- Synthesis witnesses more row-set refusals beside the creator of their rows
- A hint that asks for a newer format names the source that declares the system
- `--report-out` replaces a report file in one step
