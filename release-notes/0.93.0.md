Tone a field by its value, retire a synthesis refusal with an authored scenario, and import a cluster that serves the Gateway API.

**Breaking**

- `ess specify validate` and `ess ui check` refuse four cases an earlier release accepted
- `ess generate schema validate` and the generated Go and TypeScript explorers refuse values they accepted
- Generated React runtime files and a `graph_editor` Playwright export change
- The `x-ess-caller` of an OpenAPI operation lists callers read in more positions
- Synthesis writes different suites in 15 cases; re-pin committed suites

**Changed**

- `tone_by` draws a collection column or record field in the tone its value maps to
- `covers:` in `ess-scenario/7` retires the synthesis refusal an authored scenario was written for
- `ess infra import kubernetes` reads `gateways` and `httproutes`
- An IR holding gateways or a cloud identity is written as `infra-ir/4`, refused by earlier releases
- The React renderer draws the declared `tokens:`
