Synthesis names the identity field in the swapped half of a wrapped-value scenario at a view and tries each searched input once.

**Breaking**

- None.

**Changed**

- The swapped half of an `invariant-wrapped` scenario at a view selects its witness row by the identity field
- Releases 0.63.0 to 0.99.4 wrote a swapped half whose selector matched no row
- A pinned suite of an affected model moves when it is synthesized with this release
- A row search tries each input once after chosen values are applied, one reported model: 52.8 s to 18.2 s
- The faster row search changes no suite's bytes
