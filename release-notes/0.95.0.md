Group record fields, collapse sections and draw sections in one shared frame on an `ess-ui/1` page.

**Breaking**

- `ESS-SYNTH-025` refuses an unguarded branch that lets an input break an entity invariant
- Synthesis writes different suites for many model shapes; re-pin committed suites
- `ess specify validate` and the Rust conformance runner hold a `Decimal` to its exact value
- Generated servers and React projects change; a hand-written storage must implement `list`
- `ess ui` and a `requires:` pin of another release refuse cases they accepted

**Changed**

- A page header takes an optional `badge`
- A `record` groups its fields under headings with `groups:`
- `collapsed: true` starts a group or section closed
- `frame: shared` draws a layout column's sections in one frame
- `section.<name>.row` binds a section's first row in both renderers
