In fixture mode, a confirmed command changes the fixture rows the way the model says it does.

**Breaking**

- `ess generate types --http <binding>` refuses or leaves out a `.response` root with no published `Result`
- Generated Go and Rust decoders refuse a request whose struct breaks a declared invariant
- `ess ui test --playwright` routes the per-test fixture answers instead of marking the test `test.fixme`
- Synthesis writes scenarios for 3 model shapes it refused; re-pin committed suites

**Changed**

- `ess generate ui --target react --model <spec> --fixtures` carries the model's effects into the project
- `ess ui test --model` applies a command's effects in the terminal renderer
- `ess verify conform mutate` reports an `order-flip` whose tie synthesis cannot arrange as `unwitnessed`
