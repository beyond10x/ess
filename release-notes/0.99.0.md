An `ess-http/1` view answers CSV and wrapped bodies, commands read multipart requests, and `ess-cli` takes flags.

**Breaking**

- A route with `unknown: ignore` answers `malformed` for a path-carried `form` key of another value
- The OpenAPI `{command}.Input` of a `form` route with `unknown: ignore` is open, where it was closed
- The Go server refuses a body member no declaration names at any depth, not only the first level

**Changed**

- A view route's `representations` answer the same rows as CSV, in OpenAPI and both servers
- A route body may wrap an answer under one named member, as `{rows: array}`
- A command route may declare `request: {encoding: multipart}` and read `parts` of a file
- An `ess-cli` binding takes a required `Boolean` as a `flag` and a required `List<T>` as `repeated`
- `ess verify conform synthesize` and `run` take `--jobs` to run caller readings on threads
