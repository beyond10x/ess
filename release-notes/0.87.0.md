Show a duration as `h:mm:ss` and a byte count in B, KB, MB or GB on an `ess-ui/1` page.

**Breaking**

- `ess generate openapi` rewords an event the component does not list under `publishes:`
- A React `json` input sends parsed JSON
- Synthesis writes `not-found` for a variant an accepting guard does not claim; re-pin committed suites

**Changed**

- `unit: ms | s` sets the unit of an `as: duration` field
- A choice takes `placeholder:`, the hint shown while nothing is chosen
- `help: {text, link}` adds help to a form group or a field
- The React target shows a `javascript:` address as text
- `ess ui test` finds a row toggle in either state
