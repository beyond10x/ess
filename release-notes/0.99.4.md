Synthesis stops writing scenarios a model refuses and keeps an input's example at a leaf only presence reads touch.

**Breaking**

- None.

**Changed**

- `ess verify conform synthesize` drops scenarios whose link guard or setup the model itself refuses
- A further instance sends the input's example at a leaf another command's guard reads only for presence
- Releases up to 0.99.3 wrote those scenarios, the ones with a refused setup from 0.98.0 on
- Releases 0.99.0 to 0.99.3 sent a placeholder at such a leaf
- A pinned suite of an affected model moves when it is synthesized with this release
