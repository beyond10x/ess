Drive every control a page declares from an `ess ui test` journey.

**Breaking**

- `ess ui run --tui` sends `{id, delta}` for a row moved with `reorder`
- A React form sends an untouched toggle as its declared default
- Synthesis writes different suites for a suffixed second instance; re-pin committed suites

**Changed**

- `mark` adds a row to its collection's selection for a bulk action
- `upload: {at, file}` runs an upload action with a file
- `expect_export` holds when an export read the view
- The React target draws the controls a collection declares
- A client sort orders numbers by value
