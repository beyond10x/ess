Generate and run an `ess-ui/1` document holding host slots in React and the terminal.

**Breaking**

- The generated React runtime gains an optional `host` on its frames and on `FieldSpec`

**Changed**

- `ess generate ui --target react` generates a document holding host slots
- `src/hosts.ts` exports the `HostComponents` registry type with one entry per declared `host`
- `ess ui run --tui` draws a labelled placeholder at each host slot
- `ess-ui-test/1` refuses a step that acts inside a host slot
