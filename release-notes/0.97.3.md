Synthesis and validation repeat less work, and a downstream specification synthesizes in 24.6 s of CPU time instead of 470.7 s.

**Breaking**

- `--component` runs synthesize and report only the operations that component realises
- Mutation verdicts under `--component` can move from `unwitnessed` to `survived` or `inconclusive`
- Read-grant scenarios no longer copy the reads of other views; re-pin committed suites

**Changed**

- Synthesis binds a stored row once for all the predicates decided over it
- A model whose actors carry attributes shares the work of its caller readings
- Synthesis and `ess specify validate` make each analysis of a model once per run
- Synthesis keeps a read-grant scenario it withdrew only for a copied read
- Suites keep their bytes outside the two breaking changes
