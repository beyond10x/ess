Declare a host slot in an `ess-ui/1` document for a component the host application draws.

**Breaking**

- Synthesis writes different suites for guards over a list of identities; re-pin committed suites
- A tags input writes back no held null

**Changed**

- `host` names the component the host registers for a slot ESS does not draw
- `ess ui check` refuses a malformed host slot as `host_slots`
- `ess ui check` lists a slot that stands in for `none` as `backlog`
- `ess generate ui --target react` refuses a document holding a host slot
- An `as: tags` field draws no chip for a null entry
