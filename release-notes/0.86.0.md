Give a server-paged `ess-ui/1` collection a page-size control, and show a declared label for a value.

**Breaking**

- None.

**Changed**

- `pager: {page, size, sizes}` names the read params that carry the page and the page size
- `labels:` gives the text a field or a `badge` shows for a value
- A row toggle that runs a command shows the row's state
- A refused `ess-ui` document is reported at the path of the refused node
- An empty state may carry a `title`
