Generate types that decode the request body an HTTP binding publishes for each command.

**Breaking**

- `--names short` with `--all-commands` or `--all-views` names each input and row after its command or view
- Entity Runtime lowering refuses input `invariants:` and `prefix:` it cannot hold as preconditions
- Synthesized scenarios for a `when:` guard on an identity input change; re-pin committed suites

**Changed**

- `ess generate types --http <binding>` generates each command input as the request body the binding publishes
