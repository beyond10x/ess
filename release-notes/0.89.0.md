Send one input field as a command route's bare request body, and offer existing values in a tags input.

**Breaking**

- `ess-output-state/4` requires 0.89.0 or later of every `ess` that generates into or checks the root
- `ess generate --check` flags files of earlier releases until the root is regenerated
- `ess_http::Request` is no longer `Copy`
- An `ess-ui-test/1` step at a graph editor's inline confirm is refused without its row

**Changed**

- `request: {encoding: json, body: input.<field>}` takes one input field as the bare request body
- `suggests: {reads, value}` offers the values of a read in a tags input
- A client row filter searches text with `<a> contains <b>`
- `ess-http/1` lets a literal path segment take precedence over a variable one
- Format `ess/35` lets an `each:` entry name one row more than once
