Bind two errors of one wire name on one status without `alike:` when one always writes a field the other never writes.

**Breaking**

- `alike:` on two errors that differ by an always-written field is refused
- `ess ui check` refuses a `state.<name>` or `shell.<name>` the document does not declare
- `ess ui check` refuses a `section.<name>` or `params.<name>` that names nothing in scope
- Synthesis sends the overlap of a `distinct` guard and another refusal; re-pin committed suites

**Changed**

- `expr_roots` warns about a dotted word whose first segment is no root
- `ess ui check` resolves the root of every binding path, with or without `--model`
