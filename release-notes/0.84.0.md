Generate a UI that calls the routes its `ess-http/1` binding serves.

**Breaking**

- Authored success steps and grant denial scenarios check more; re-pin committed suites
- A library caller of `SuiteProvenance::of` must run an authored suite with `Runner::run_admitted`
- Generated Rust and Go servers refuse a `Timestamp` that is not RFC 3339 and an undeclared body member
- A generated Rust server's `decode_system_event` refuses a log envelope an older server wrote
- `ess ui check` and the React target refuse account menu entries that renderers dropped or misread

**Changed**

- `ess generate ui` and `ess ui run --tui` take `--http <binding>`
- The terminal renderer addresses a row action's confirm by the view's row key
- In the terminal renderer a record's actions see the row the record shows
- The React target runs an `account_menu` entry's `sets` and `navigate`
