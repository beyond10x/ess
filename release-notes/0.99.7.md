Synthesis arranges a branch beside a stored-link refusal on the row the subject links to.

**Breaking**

- None.

**Changed**

- A branch beside a refusal comparing a stored link with an input is sent the row the subject links to
- A link copied from another row is followed through that row's creation
- Releases 0.99.4 to 0.99.6 refused such a branch with "no candidate of the 0 tried"
- Releases 0.99.1 to 0.99.3 wrote it with another row that failed on the model's interpreter
- A pinned suite of an affected model moves when it is synthesized with this release
