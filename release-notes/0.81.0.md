Generate types for an `Optional<Binary64>` field that may be null.

**Breaking**

- Synthesis changes `when_related:` and wrong-state scenarios in 3 cases; re-pin committed suites
- `ess generate types --root <command>.response` refuses a command that declares no response

**Changed**

- `ess generate types` realizes an `Optional<Binary64>` field declared `null_when_absent` or `omitted_or_null`
- The published document schema admits a name written `id:` or `component:`
